# Level-by-level plan (Combat Rogue, Night Elf)

> Built 2026-11-07 from current WoW Forever guides (sources at the bottom). **Every level: visit a rogue trainer if anything is new, spend your talent point, check bag space.** Trainer and talent window in-game win if anything here doesn't match.

## How to spend talent points
Press `N` → click the talent. Combat build = **Warcraft Tavern's Combat leveling build** ([open it in the calculator](https://www.warcrafttavern.com/forever/tools/talent-calculator/rogue#?t=A11B11000555669688bdeeffhggiiiiimmpmmmbfA22277722aa444)). It starts with 2 points in the **Assassination** tree, then goes into **Combat**. Mobalytics' guide uses the same opening, so two guides agree.

⭐ = big power spike, don't skip.
