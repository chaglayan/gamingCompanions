# PoE2 Companion 🗡️

My Path of Exile 2 companion. First league here: **1.0 + Conquerors of Wraeclast (11 Dec 2026)**. Claude helps pick a starter, tracks my character and build, and plans each session.

Start with [`journal/overview.md`](journal/overview.md). League info and launch checklist: [`guides/league-1.0.md`](guides/league-1.0.md).

## How to use it (from the phone)

1. Snap photos of the screen (list below).
2. Send them to Claude. Photos aren't kept; Claude writes down what's in them.
3. Ask things like:
   - "Which starter should I play?"
   - "Is this item an upgrade?" (+ tooltip photos)
   - "What should I do this session?"
   - "My character feels squishy, why?"

## Photo checklist (most useful first)

| What | Why |
|---|---|
| Character sheet (`C`), defences tab | Life/ES, resistances, Spirit |
| Skill gems (`G`) | Skills, supports, levels |
| Passive tree (`P`) | Points spent, next nodes |
| Gear tooltips (hover each slot) | Mods for upgrades |
| Atlas / league UI | Endgame progress |

Tips: one window per photo, straight at the screen. Hold `Alt` on items for advanced mod info.
